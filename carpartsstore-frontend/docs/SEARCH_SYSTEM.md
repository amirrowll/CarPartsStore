# سیستم جستجوی پیشرفته PinpartStore

## 🎯 ویژگیهای اصلی

### ۱. جستجوی چندکلمهای هوشمند
- جستجو در ۱۰ فیلد مختلف به صورت همزمان
- پشتیبانی از جستجوی فازی (Fuzzy Search)
- عدم حساسیت به حروف کوچک و بزرگ
- جستجو در تگها و هشتگها

### ۲. فیلترهای پیشرفته
- **برند خودرو**: Chinese, Saipa, IranKhodro, Other
- **مدل خودرو**: پراید، تیبا، دنا، ساینا، کوییک، پژو ۲۰۶، سمند، سورن و...
- **برند قطعه**: Bosch, Valeo, Denso و سایر برندها
- **شماره قطعه**: جستجو بر اساس کد OEM و شماره فنی
- **سازگاری**: جستجو در لیست خودروهای سازگار
- **جنس قطعه**: پلاستیک، فلز، لاستیک، سرامیک، کامپوزیت
- **گارانتی**: ۶ ماه، ۱ سال، ۲ سال، ۳ سال، مادامالعمر
- **محصولات ویژه**: فیلتر فقط محصولات ویژه

### ۳. مرتبسازی پیشرفته
- تاریخ ایجاد (جدیدترین/قدیمیترین)
- ترتیب نمایش (اولویت نمایش)
- نام محصول (الفبایی)
- برند قطعه
- برند خودرو
- مدل خودرو
- شماره قطعه

### ۴. قابلیتهای ویژه
- **تگبندی هوشمند**: استفاده از تگهای از پیش تعریف شده
- **هشتگهای محبوب**: نمایش هشتگهای پرکاربرد
- **فیلترهای ترکیبی**: استفاده از چندین فیلتر به صورت همزمان
- **صفحهبندی**: نمایش ۲۴ محصول در هر صفحه
- **جستجوی سریع**: دسترسی سریع از صفحه اصلی

## 🏗️ معماری سیستم

### Backend (ASP.NET Core)
```
ProductFilterDto.cs
├── Search: جستجوی چندکلمهای
├── Brand: برند قطعه
├── CarBrand: برند خودرو
├── CarModel: مدل خودرو
├── PartNumber: شماره قطعه
├── CompatibleCars: سازگاری
├── Material: جنس
├── Warranty: گارانتی
├── Tags[]: تگها
├── Hashtags[]: هشتگها
├── IsFeatured: محصولات ویژه
├── SortBy: مرتبسازی
└── Page/PageSize: صفحهبندی

ProductService.cs
├── GetProductsAsync(): منطق جستجوی پیشرفته
├── GetPopularTagsAsync(): تگهای محبوب
├── GetPopularHashtagsAsync(): هشتگهای محبوب
├── GetDistinctCarBrandsAsync(): برندهای خودرو
├── GetDistinctCarModelsAsync(): مدلهای خودرو
├── GetDistinctMaterialsAsync(): جنسها
└── GetDistinctWarrantiesAsync(): گارانتیها
```

### Frontend (React + TypeScript)
```
components/
├── AdvancedSearch.tsx
│   ├── جستجوی اصلی با فیلترهای پیشرفته
│   ├── فیلترهای ترکیبی
│   ├── تگها و هشتگها
│   └── مرتبسازی و صفحهبندی
│
├── QuickSearch.tsx
│   ├── جستجوی سریع در صفحه اصلی
│   ├── انتخاب برند و مدل خودرو
│   └── جستجوهای پرطرفدار
│
pages/
├── AdvancedSearchPage.tsx
│   ├── نمایش نتایج جستجو
│   ├── صفحهبندی
│   └── آمار و اطلاعات
│
└── SearchTestPage.tsx
    └── تست کامل سیستم جستجو
```
